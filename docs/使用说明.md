# 使用说明

面向用插件做片子的轴效。每一节都写清楚**点哪、看到什么算对、不对时是什么样**。

第一次用之前，先按 README 的「装法」把插件放好、点过「重新扫描自动化目录」。

---

## 开始之前

- **先打开视频再点功能。** 「导入 txt + 自动粗轴」「加屏字」「7/8/9 工作台」都要视频，
  没有视频时插件会明确告诉你「先打开视频」。
- **字幕文件新建一个就行**，插件会在第一次跑功能时把需要的样式补进去（缺哪个补哪个，
  已有的不动）。
- 插件用到的样式名：`Text CN` / `Text JP`（对白）、`Text CN Top` / `Text JP Top`（次要）、
  `OP CN/JP`、`ED CN/JP`、`Insert CN/JP`（歌词）、`Note`（注释）、`Screen`（屏字）。
  中日是**成对**的，插件靠这个配对。

## 一、导入翻译交来的 txt

菜单：**轴效 → 1 导入 txt**

1. 点一次，选一个 txt。插件读第一行判断是中文还是日文（三成以上的行带假名算日文）。
2. **日文和中文各点一次、各导一遍。** 不要想着一次导两半——插件故意不合并，
   中日各是一组行，靠顺序对应（日文第 N 句 ↔ 中文第 N 句）。
3. 导入后字幕里会有：日文行（`Text JP`，图层 0）、中文行（`Text CN`，图层 1），时间都是 0，
   等你打轴。

**看得对不对**：插件会把识别结果和目前文件里中日各有多少句写在日志里。
两边句数不一样时会提示「句数对不上，同步时间前先查漏行」。

**重复导入**：同一份 txt 再导一次，插件会说「这份 txt 文件里已经有了（一句不差）」，
不会重复加行。这是故意的——重复导入过一次的话，同步时间会整体错位。

**txt 的编码**：只认 UTF-8。GBK 的 txt 会乱码，让翻译存成 UTF-8。

## 二、打轴、分主次、标歌词

打完轴之后（这是你自己的活，插件不替你打轴）：

| 想换成 | 点 |
|---|---|
| 主要（底部） | 轴效 → 2 设为主要（底部） |
| 次要（顶部） | 轴效 → 2 设为次要（顶部） |
| OP 歌词 | 轴效 → 2 设为 OP 歌词 |
| ED 歌词 | 轴效 → 2 设为 ED 歌词 |
| 插曲歌词 | 轴效 → 2 设为插曲歌词 |

**中文、日文随便选哪边都行**，另一边会自动跟着换（因为成对）。

**歌词**：OP/ED/插曲各有一对中日样式，位置在样式里定（见下面「歌词定位」）。
插曲经常和对白同时出现，所以插件把插曲样式放在画面顶部角上，中日叠在一起。

## 三、同步时间（中日对时间）

菜单：**轴效 → 5 同步时间（中日）**

打好一边的轴，点一下，时间按顺序复制给另一边。插件自己判断哪边是「已经打好轴的那边」
（有时间的那边），你不用选。

**句数对不上时插件会停下来**，不硬同步，并告诉你是日文多还是中文多。先查：

- 是不是同一个 txt 导了两次？删掉多出来的那一组。
- 是不是翻译漏了一句/多了一句？补齐或删掉。
- 查完再点一次。

## 四、加注释

菜单：**轴效 → 3 加注释**

选中要注释的那一行，点一下。插件在这行**下面**插一条 `Note` 样式、时间照抄的行，
文字预填「注：」，并且自动选中新行——你直接接着打字就行。

注释在画面上放左上角（对齐 7）。

## 五、加屏字（画面上的字）

菜单：**轴效 → 4 加屏字**

1. **先把播放头停到屏字要出现的那一帧**（要在视频上停，插件取「当前帧」的时间）。
2. 选中一行对白，点一下。插件在这行下面插一条 `Screen` 样式的行，
   时间 = 当前帧起 2 秒，文字预填「屏字」，位置默认在画面正中 `\pos(画面中心)`。
3. 把它拖到该在的地方，或者直接写坐标。
4. 有黑边的话，最好量着画面边缘写死 `\pos`，别靠 MarginV——不同播放器对黑边的处理不一样。

## 六、歌词定位（OP/ED 放哪）

歌词放哪要看画面，插件不写死，让你在画面上拖，它负责把结果写成对齐方式 + 边距。

1. **轴效 → 6 歌词定位：开始** → 弹个小框选 OP / ED / 插曲。
2. 插件会在字幕最底下铺 2 条辅助线（黄的安全框、青的中线和三分线），
   再放中日两条示例行（用当前样式的位置和字号画的）。
3. 用左边工具栏的**拖动**工具，把两条示例行拖到想要的位置。
4. **轴效 → 6 歌词定位：记录**。插件算两条示例行的实际外框，吸到最近的辅助线或
   另一条语言上，把对齐方式、左右边距、垂直边距写进那对歌词样式，然后清掉辅助行。
   日志会报「××吸上了」还是「没吸附」。
5. 想重来：**轴效 → 6 歌词定位：取消**（只清辅助行和示例，样式不动）。

**吸不上怎么办**：拖动时贴辅助线差不到画面高的 3% 就会吸上。日志说「没吸附」时，
插件是按示例行所在的区域自己定对齐（左三分之一左对齐、右三分之一右对齐、上半顶对齐、
下半底对齐），结果不一定难看，但想精确就再拖近一点重记录一次。

## 七、特效样式（工作台第一页）

菜单：**轴效 → 7 特效样式**（第一次用会让你下载组件）

窗口左边是几页，右边是**带声音的预览**：所选行前后各 5 秒的片段，用 Aegisub 自带的
xy-VSFilter 渲染，和成片效果基本一致。

1. 在 Aegisub 里选中要加特效的行（屏字、歌词）。
2. 点菜单打开工作台，左边**特效样式**页会列出可用的预设（淡入淡出、发光、双层描边、
   入场动画……）。
3. 选一个预设，点预览看效果。位置不对就在预览画面上点一下——插件把 `\pos` 记进去。
4. 满意了点**应用**。改动回到 Aegisub，**整批一步撤销**（Ctrl+Z 撤掉整次应用）。

工作台里的改动**不会直接写进字幕**，都是攒着，点「应用」才回去。所以放心试。

## 八、卡拉OK特效（工作台第二页）

菜单：**轴效 → 8 卡拉OK特效**

1. 在 Aegisub 里选中歌词行（一般选 OP/ED 的日文行）。
2. 工作台默认停在**卡拉OK**页。这里可以：
   - **自动打 `\k`**：按字平均分（英文按音节权重）。
   - **套社区模板**：从 GitHub 上的模板合集里挑（第一次要联网下载，只读本地索引 + 按需下）。
     也可以用**字幕里已有的模板行**（自己写的，或者从成品里扒的）。
   - **逐字关键帧时间轴**（下面细说）。
3. 点预览听效果、看画面，满意点应用。

### 逐字关键帧时间轴（手动打点）

whisper 做逐字时间对唱腔不准，所以这个功能是**让你像做视频一样手动打关键帧**：

- 时间轴上是这一句的波形，每个字一个 ◆。
- **播放时按 K** 在当前位置打一个点（下一个字的开口时间）。
- **点某个字**可以试听那一段。
- **右键**：
  - 在一个 ◆ 上右键 → 和上一个字**合并**（两个字连着唱，用同一拍）；
  - 在最后一个字右边空白处右键 → **拆开**，多出一拍空音节
    （同一个字拖长音唱，写成没有字的 `\k`）。
- **滚轮**缩放，**Shift+滚轮**平移。

打完点写回的 `\k` 是标准写法，Aegisub 和播放器都认。

## 九、AI 助手（工作台第三页）

菜单：**轴效 → 9 AI 助手**

第一次用要先填接口：**协议**（OpenAI 兼容 / Anthropic）、**Base URL**、**Key**、**模型名**。
Key 只存在你本机的组件目录 `ai.json` 里，不会上传到别处。

配好以后可以直接跟它说人话，比如「把选中的这几行加个淡入」「第 30 行的字太长了，
帮我断行」「这段歌词给我写个卡拉OK特效模板」。AI 能读你的字幕、改行、插行、删行、
加样式，也能让它渲染某一时刻的画面看一眼再改。

**改动一样是攒着的**，点「应用」才写回 Aegisub，一步撤销。

## 十、测试 / 验收清单

改过脚本或升级之后，按这个单子过一遍。测试素材在 `轴效测试\` 文件夹
（`测试视频.mp4` + 四组 txt + 歌词文件夹 + 长间隔），详细预期值见那里的
`测试说明.txt`。

**每次测试前的固定动作**

1. 改过脚本：自动化 → 自动化管理器 → 点「重新扫描自动加载目录」。
2. 文件 → 新建字幕。
3. 视频 → 打开视频，选要测的 mp4。
4. 音频会跟着视频自动加载；没加载就 音频 → 从视频打开音频。

**怎么算「测对了」**

1. 不只看结果对不对，还要看**不该变的有没有变**。
2. 每一步做完按 **Ctrl+Z**，应该能一次撤销整步操作。
3. 样式只在第一次运行时创建。在样式管理器里改过字体颜色之后，插件不会覆盖掉。
4. 最后「文件 → 另存为」存成 ass，用记事本打开看一眼，格式没坏。
5. 出问题告诉开发的人三样：**点了哪个功能、选中了哪几行、看到了什么**（截图最好）。

## 各组习惯不同，插件留了余地

插件只把**各组都这么做**的结构写死（中日分样式各自成行、次要台词用顶部样式对、
注释单独样式多数放左上），外观一律跟你的样式方案或 Default，按作品自己调。
所以不同组用起来，「插件管的部分」是一样的，「长什么样」由你自己的样式库决定。
